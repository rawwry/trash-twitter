{{ icon('help', 16) }} So funktionieren Regeln
Wann?
Jedes neu archivierte Posting wird geprüft, sobald sein Wortlaut da ist – auch wenn jemand den Text von Hand korrigiert. Vorhandene Postings nur über „Auf … anwenden“.
Was genau?
Ganze Wörter, Groß-/Kleinschreibung egal. verstorb* findet alles, was so anfängt, *katze alles, was so endet. Mehrere Wörter in einer Zeile müssen genau so hintereinander stehen.
Nur hinzufügen
Regeln vergeben Tags, sie nehmen nie welche weg. Von Hand vergebene Tags bleiben immer.
Rückgängig
Die App merkt sich, was eine Regel vergeben hat. „Automatisch vergebene entfernen“ nimmt genau diese Tags wieder ab.
